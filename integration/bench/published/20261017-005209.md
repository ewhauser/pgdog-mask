# pgdog-mask benchmark

2026-10-17T06:52:16Z on Erics-MacBook-Pro: Apple M3 Max, 16 cores, Darwin 25.5.0. Postgres 16.14 (Homebrew), pgbench 16.14, PgDog `b90f1926`, pgdog-mask `6949462`.

3 runs of 10s per row, 16 clients, 4 threads, scale 20, 4 PgDog workers. Values are medians across runs.

Targets:

- **Postgres direct**: pgbench connects to Postgres.
- **PgDog**: PgDog without the plugin, the baseline for masking.
- **exempt**: PgDog with the plugin, as a user no policy masks.
- **masked**: PgDog with the plugin, as a masked user.
- **masked, raw search**: PgDog with the plugin, as a masked user whose rule has `search = "raw"`. Only measured for `lookup`.
